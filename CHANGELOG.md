# Changelog

## 0.3.0 — first public source release

- Portable Python package, stdio MCP, JSON CLI and Python operation dispatcher.
- Direct TypeSafe and OpenRouter routes with separate response and accounting contracts.
- Seven coding recipes, exact settled-result reuse, durable shared reservations and immutable typed feedback.
- Content/pointer-bound context plans with mandatory pins and preserved source access.
- Native pi extension with a bounded shell-free CLI bridge.
- Offline demo and structurally paired workflow-report comparison.
- Independent review fixes for threshold binding, direct-provider billing shape, source byte hashes, policy initialization and oversized reported costs.

Extracted from the author's private Jev Reflex integration into a clean repository. Private configuration, credentials, ledgers and Git history were not imported. This release is not a TypeSafe model release or an official TypeSafe product.
